# CSE422-Project-Medical-Student-
CSE422 Machine Learning Lab Project — dataset analysis, preprocessing, EDA, supervised learning models, neural network, K-Means clustering, and model evaluation.

This repository contains our CSE422 Machine Learning Lab Project, including dataset analysis, exploratory data analysis (EDA), data preprocessing, supervised machine learning models, neural network implementation, K-Means clustering, and model performance evaluation.

* Dataset description and analysis
* Exploratory Data Analysis (EDA)
* Data preprocessing
* Train-test splitting
* K-Nearest Neighbors (KNN)
* Decision Tree
* Logistic Regression
* Neural Network
* K-Means Clustering
* Model comparison and evaluation
* Confusion matrices, ROC curves, AUC, precision, recall, and accuracy analysis
* Final project report
